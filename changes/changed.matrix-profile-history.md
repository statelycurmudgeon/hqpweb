- **Matrix profile is on the signal card.** It's part of the signal chain, so it now has a row
  after Rate, always shown: the profile in use, **Default** for none chosen, or "No profiles
  created", which still opens to say where to set them up. That's said for HQPlayer Desktop or
  Embedded, in full the first time and in a few words after "Show less". A name too long for
  the row moves below its label rather than being cut off. It's gone from Advanced.
- **What's learned is kept in two sets: with HQPlayer's DAC correction running, and without.**
  Correction is heavy, so what kept up and what fell behind differ. hqpweb follows HQPlayer's own
  report of whether it runs, not profile names. Other matrix processing isn't told apart; if
  you need that, ask. History from before this applies either way.
